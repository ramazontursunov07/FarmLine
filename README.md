# FarmLine
FarmLine — fermerlar va chorvachilik/parrandachilik bilan shug'ullanuvchi tadbirkorlar uchun mo'ljallangan platforma. Tizim orqali fermerlar o'z xo'jaligidagi mol-hol/parranda holatini, kasallik va davolash jarayonlarini, kirim-chiqim hisobini va ombor zaxirasini bir joyda boshqarishlari mumkin.
